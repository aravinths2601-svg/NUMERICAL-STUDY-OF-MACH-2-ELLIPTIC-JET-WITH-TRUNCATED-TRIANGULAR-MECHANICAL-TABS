 NUMERICAL-STUDY-OF-MACH-2-ELLIPTIC-JET-WITH-TRUNCATED-TRIANGULAR-MECHANICAL-TABS

 Project Overview: 

This project presents a Computational Fluid Dynamics (CFD) investigation of a Mach 2 elliptic jet equipped with truncated triangular mechanical tabs. The study evaluates the influence of tab-induced flow disturbances on supersonic jet characteristics.

Objectives :

•Analyze shock-cell structures in a Mach 2 elliptic jet.
•Investigate vortex generation due to mechanical tabs.
•Evaluate jet spreading and mixing enhancement.
•Study the effect of tab geometry on flow-field development.

Software Used :

•ANSYS Fluent
•ANSYS Meshing
•CFD Post

Methodology :

1. Create the nozzle geometry.
2. Generate computational mesh.
3. Define boundary conditions.
4. Perform CFD simulations.
5. Analyze velocity, pressure, Mach number and turbulence contours.

Results :

•Enhanced jet mixing.
•Increased streamwise vortex formation.
•Modified shock-cell structure.
•Improved entrainment of ambient air.

Applications : 

•Aerospace propulsion systems
•Supersonic exhaust nozzles
•Missile and rocket propulsion
•High-speed flow control
